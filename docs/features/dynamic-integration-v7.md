# V7 动态内容整合

本版仍是隔离代码与本地预览，没有部署、开通账户、修改域名或创建持续访问凭据。V6附件保留，可独立回退。

## 内容如何进入博客

- 首页保留静态文章，在相同设计体系中显示动态服务中已发布的文章，支持继续加载。公开读取不携带登录令牌或cookie，故障不影响静态文章。
- 搜索合并Pagefind的静态结果与动态服务的公开搜索结果；远端内容作为文本处理，不执行返回的HTML。未配置API时保留原静态搜索。
- RSS与Atom由Worker合并本次构建的静态文章摘要和D1中当前已发布的文章，按发布时间取最近25篇。撤回后不再公开输出。构建清单明确排除草稿、加密文章与正文。
- 配置API后，构建生成两条准确的Cloudflare Pages重定向，把原rss.xml/atom.xml订阅地址指向动态合并订阅。保留其他规则，同路径冲突则阻止构建；尚未在Cloudflare验证。
- 旧静态Markdown和原有文章仍然保留。动态文章仍存于D1，不会自动变成Git文件。搜索动态内容是运行时查询，不是写进Pagefind磁盘索引。动态页面SEO与sitemap静态收录尚未实现服务端渲染，不能把站内可搜索等同于搜索引擎已收录。

## 构建和发布顺序

标准build开始先使Worker静态摘要清单失效；Astro成功后生成public community-static-feed.json，后续校验通过才生成backend/src/static-feed.mjs。构建失败不可部署Worker旧清单。

批准上线之后，应先建立隔离测试API和身份服务，验证数据库与身份权限；再用真实公开API地址构建前端与Worker，测试首页、搜索、合并订阅和旧订阅重定向。更新静态文章后必须重新构建并同时更新Worker清单，否则合并订阅的静态部分仍是上次构建的内容。动态发表无需触发静态构建。

## 尚未启用的服务

API、D1和OIDC仍未配置，登录、云发布、评论、点赞、收藏和统计不会在当前附件中伪装运行。真实服务的启用步骤、权限及费用见backend/README.md。统计默认关闭。QQ保留真实歌单入口，不提供站内音频播放。
