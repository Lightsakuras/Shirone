# 我的第一篇博客

博客开张了。

这个站点没有用服务器，也没有花一分钱：源码托管在 GitHub 上，构建和部署全部交给 Cloudflare Pages 自动完成，页面内容靠 AI 辅助生成和修改。

## 这里会写些什么

- 视觉传达与平面设计的练习、作品
- 游戏攻略和日常：《方舟：飞升》《僵尸毁灭工程》《鸣潮》等
- 学习笔记和生活随想

## 搭建过程速记

1. Fork 主题仓库到自己的 GitHub 账号
2. 本地用 AI IDE 克隆仓库、安装依赖、修改站点配置
3. Cloudflare Pages 连接 GitHub 仓库，推送即自动部署
4. 以后想改内容，直接跟 AI 许愿，或者自己写 Markdown

第一篇就先写到这里，欢迎以后常来。
